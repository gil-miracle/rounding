# 컨퍼런스 독려 이벤트 (퀴즈 + 사다리타기)

교회 컨퍼런스 홍보용 웹 이벤트입니다. HTML / CSS / JavaScript 만 사용했고,
설치나 서버 없이 **`index.html` 을 브라우저로 열면 바로 실행**됩니다.

> 디자인은 임시(기능 확인용)입니다. 시안이 나오면 `css/style.css` 만 손보면 됩니다.

---

## 화면 흐름

```
인트로  →  퀴즈(4지선다 1문제)  →  상자 선택(6개)  →  사다리타기  →  엔딩
```

1. **상자 선택** — 상품 이름은 숨겨져 있고, 상자 번호와 **남은 수량(`7 / 10`)** 만 보입니다. 수량이 0이면 `품절` 로 바뀌고 고를 수 없습니다.
2. **사다리타기** — **`스타트` 버튼**을 누르면 색깔이 다른 원 5개가 동시에 내려갑니다. 선은 남지 않고 짧은 잔상만 따라갑니다.
3. **공개** — 다섯 원이 바닥에 닿으면 아래 5칸이 가운데로 모여 하나가 되고, 사다리는 접혀서 사라지며 **"당신이 고른 상품은 ○○입니다" + QR** 이 화면 가운데로 올라옵니다.

사다리 결과는 상품과 관계없는 연출입니다. 상품은 고른 상자로 이미 정해져 있습니다.

상단에 **이전 / 다음** 버튼이 있어 자유롭게 이동할 수 있습니다. (키보드 ← → 도 동작)
가운데 **MIRACLE** 글자를 누르면 언제든 처음 화면으로 돌아갑니다. (글자는 `nav.brand` 로 바꿀 수 있습니다)

## 화면 크기

아이패드 세로(768~834px) 기준으로 맞춰져 있고, 아이폰 등 좁은 화면에서도 자동으로 줄어듭니다.

---

## 폴더 구조

```
index.html            화면 구조
css/style.css         스타일 (디자인 시안 반영은 이 파일에서)
js/config.js          ★ 이벤트 내용 설정 — 보통 이 파일만 고치면 됩니다
js/ladder.js          사다리 생성 · 경로 계산 · 애니메이션
js/app.js             화면 전환, 수량 관리, 전체 흐름
assets/qr/*.svg       QR 이미지 (지금은 샘플 자리 이미지)
```

## 상품 · QR · 수량 설정

`js/config.js` 의 `prizes` 배열 6개를 고치면 됩니다.

```js
prizes: [
  { id: 'cafe', emoji: '☕', name: '카페 기프티콘', note: '아메리카노 Tall',
    qrImage: 'assets/qr/cafe.png', stock: 10 },
  ...
]
```

| 항목 | 설명 |
| --- | --- |
| `id` | 수량 저장에 쓰는 고유 이름. **한 번 정하면 바꾸지 마세요** (바꾸면 수량이 초기화됩니다) |
| `name` / `emoji` | 사다리 도착 후 공개될 이름 |
| `note` | QR 아래 안내 문구 |
| `qrImage` | QR 이미지 경로 |
| `stock` | 준비한 수량. 0이 되면 선택 불가. **줄을 지우면 수량 제한 없음** |

### QR 이미지 넣는 법

1. 기프티콘/링크 QR 이미지를 `assets/qr/` 에 넣습니다. (png, jpg, svg 모두 가능)
2. 해당 상품의 `qrImage` 경로를 바꿉니다.

경로가 틀리면 화면에 **"QR 이미지를 찾을 수 없어요" + 찾던 파일 경로**가 표시되니 바로 확인할 수 있습니다.

### 수량 초기화

수량은 **그 기기(브라우저)의 localStorage** 에 저장됩니다. 태블릿 두 대로 운영하면 기기마다 따로 셉니다.

- 주소 끝에 `?reset=1` 을 붙여 한 번 열면 처음 상태로 돌아갑니다 → `index.html?reset=1`
- `config.js` 의 `stock.storageKey` 를 바꿔도 초기화됩니다
- 개발자 콘솔에서 `EventStock.reset()` 도 가능합니다

## 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
| --- | --- |
| `intro` | 제목, 부제, 일시/장소, 시작 버튼 문구, 로고 이미지 |
| `quiz` | 문제, 보기 4개, `answerIndex`(정답 번호, 0부터), 정답/오답 문구 |
| `quiz.allowRetry` | `true` 면 맞출 때까지 재도전, `false` 면 한 번에 판정하고 정답 공개 |
| `prizeScreen` | 상자 화면 문구, 상자 그림·번호, 품절 문구 |
| `prizes` | 상품 6개 (이름 · QR · 수량) |
| `stock` | 수량 저장 사용 여부와 저장 이름 |
| `ladder.colors` | 내려가는 원 5개의 색깔 |
| `ladder.tailLength` | 원 뒤에 남는 잔상 길이(px) |
| `ladder.autoStart` | 기본은 `false`(스타트 버튼으로 시작). `true` 로 바꾸면 화면에 들어오는 순간 자동으로 출발합니다 |
| `ladder.traceMs` | 원이 내려가는 시간(ms) |
| `ladder.revealLead` | 공개 카드 첫 줄 문구 |
| `nav.showBack` / `showNext` | 상단 이동 버튼 표시 여부 — 행사 당일엔 꺼두는 것도 방법입니다 |
| `ending` | 마무리 문구, 신청 링크 QR, `autoRestartSec`(0보다 크면 자동으로 처음 화면 복귀) |

## 알아두면 좋은 점

- **수량 차감 시점**: 상자를 고르는 순간이 아니라 **사다리 도착 후 상품이 공개될 때** 1개 줄어듭니다. 중간에 그만두면 차감되지 않습니다.
- **재도전 가능**: 상단 `이전` 으로 상자 선택 화면까지 돌아갔다가 다시 들어오면 새로 뽑을 수 있습니다(수량도 다시 차감). 한 사람이 여러 번 돌리는 걸 막으려면 `nav.showBack: false` 로 두세요.
- **상자 번호는 고정**입니다. 같은 번호는 항상 같은 상품이라, 시간이 지나면 참여자들끼리 알게 될 수 있습니다. 필요하면 중간에 `prizes` 순서를 바꿔주세요.
- 인터넷 연결 없이도 동작합니다. (외부 라이브러리·폰트 미사용)
