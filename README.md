# 컨퍼런스 독려 이벤트 (퀴즈 + 사다리타기)

교회 컨퍼런스 홍보용 웹 이벤트입니다. HTML / CSS / JavaScript 만 사용했고,
설치나 서버 없이 **`index.html` 을 브라우저로 열면 바로 실행**됩니다.

> 디자인은 임시(기능 확인용)입니다. 시안이 나오면 `css/style.css` 만 손보면 됩니다.

---

## 화면 흐름

```
인트로 → 퀴즈(4지선다 1문제) → 상자 선택(6개) → 짜잔! 상품 공개 → 사다리타기 → 엔딩
```

1. **상자 선택** — 상품 이름은 숨겨져 있고, 상자 번호와 **남은 수량(`7 / 10`)** 만 보입니다. 수량이 0이면 `품절` 로 바뀌고 고를 수 없습니다.
2. **짜잔! 상품 공개** — 고른 상자가 무엇이었는지 **상품 사진 + 이름**으로 공개합니다. 이때 그 상품의 수량이 1개 줄어듭니다.
3. **사다리타기** — **`스타트` 버튼**을 누르면 색깔이 다른 원 5개가 동시에 내려갑니다. 선은 남지 않고 짧은 잔상만 따라갑니다.
4. **도착** — 다섯 원이 바닥에 닿으면 아래 5칸이 가운데로 모여 하나가 되고, 사다리는 접혀서 사라지며 **컨퍼런스 신청폼 QR** 이 화면 가운데로 올라옵니다.

> **상자와 사다리는 별개입니다.** 상품은 2번에서 이미 정해지고,
> 사다리는 어느 줄로 내려와도 모두 **신청폼**으로 모입니다. (`config.js` 의 `form` 설정)

상단에 **이전 / 다음** 버튼이 있어 자유롭게 이동할 수 있습니다. (키보드 ← → 도 동작)
가운데 **MIRACLE** 글자를 누르면 언제든 처음 화면으로 돌아갑니다. (글자는 `nav.brand` 로 바꿀 수 있습니다)

## 화면 크기

아이패드 세로(768~834px) 기준으로 맞춰져 있고, 아이폰 등 좁은 화면에서도 자동으로 줄어듭니다.

---

## 폴더 구조

```
index.html            화면 구조
css/style.css         스타일 (디자인 시안 반영은 이 파일에서)
js/config.js          ★ 이벤트 내용 설정 — 보통 이 파일만 고치면 됩니다
js/ladder.js          사다리 생성 · 경로 계산 · 애니메이션
js/app.js             화면 전환, 수량 관리, 전체 흐름
assets/prize/         ★ 상품 사진 (짜잔 화면용) — 여기에 넣어주세요
assets/qr/*.svg       QR 이미지 (지금은 샘플 자리 이미지)
```

## 상품 · 이미지 · 수량 설정

`js/config.js` 의 `prizes` 배열 6개를 고치면 됩니다.

```js
prizes: [
  { id: 'cafe', emoji: '☕', name: '카페 기프티콘', note: '아메리카노 Tall',
    image: 'assets/prize/cafe.png', qrImage: 'assets/qr/cafe.png', stock: 10 },
  ...
]
```

| 항목 | 설명 |
| --- | --- |
| `id` | 수량 저장에 쓰는 고유 이름. **한 번 정하면 바꾸지 마세요** (바꾸면 수량이 초기화됩니다) |
| `name` / `emoji` | 짜잔 화면에 공개될 이름 |
| `note` | 이름 아래 안내 문구 |
| `image` | **짜잔 화면에 크게 보여줄 상품 사진** |
| `qrImage` | 상품 기프티콘 QR (엔딩에서 표시). 필요 없으면 `''` |
| `stock` | 준비한 수량. 0이 되면 선택 불가. **줄을 지우면 수량 제한 없음** |

### 이미지 넣는 법

- **상품 사진** → `assets/prize/` 에 넣습니다. 가로:세로 **4:3**(예: 800×600)이 가장 잘 맞습니다.
- **QR 이미지** → `assets/qr/` 에 넣습니다. 신청폼 QR은 `form.image`, 상품 QR은 각 상품의 `qrImage`.
- png / jpg / svg / webp 모두 됩니다. 확장자를 바꾸면 `config.js` 의 경로도 함께 바꿔주세요.

파일이 없거나 경로가 틀리면 화면에 **넣어야 할 파일 경로**가 그대로 표시되니 바로 확인할 수 있습니다.

### 수량 관리 (행사 중에 바로 조정)

첫 화면 **우측 위 톱니바퀴(⚙️)** 를 누르면 수량 관리 창이 열립니다.

- 상품마다 **남은 수량**과 **전체 수량**을 직접 고칠 수 있습니다 — 현장에서 상품이 추가되거나 줄었을 때 쓰세요
- **처음 수량으로** → `config.js` 에 적힌 원래 수량으로 되돌립니다
- **저장**을 눌러야 반영됩니다. 닫기나 `Esc` 로 나가면 바뀐 값은 버려집니다
- 톱니바퀴는 **첫 화면에만** 보입니다. 아예 감추려면 `config.js` 의 `stock.hideButton: true`

수량은 **그 기기(브라우저)의 localStorage** 에 저장됩니다. 태블릿 두 대로 운영하면 기기마다 따로 셉니다.
주소 끝에 `?reset=1` 을 붙여 열거나(`index.html?reset=1`), `stock.storageKey` 를 바꿔도 초기화됩니다.

## 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
| --- | --- |
| `intro` | 제목, 부제, 일시/장소, 시작 버튼 문구, 로고 이미지 |
| `quiz` | 문제, 보기 4개, `answerIndex`(정답 번호, 0부터), 정답/오답 문구 |
| `quiz.allowRetry` | `true` 면 맞출 때까지 재도전, `false` 면 한 번에 판정하고 정답 공개 |
| `prizeScreen` | 상자 화면 문구, 상자 그림·번호, 품절 문구 |
| `prizes` | 상품 6개 (이름 · 사진 · QR · 수량) |
| `reveal` | 짜잔 화면 문구 (`짜잔! 🎉`, `이 상품은`, 다음 버튼) |
| `form` | **사다리 도착 지점 = 컨퍼런스 신청폼** (제목 · QR 이미지 · 안내 문구) |
| `stock` | 수량 저장 사용 여부, 저장 이름, 톱니바퀴 숨김(`hideButton`) |
| `ladder.colors` | 내려가는 원 5개의 색깔 |
| `ladder.tailLength` | 원 뒤에 남는 잔상 길이(px) |
| `ladder.autoStart` | 기본은 `false`(스타트 버튼으로 시작). `true` 로 바꾸면 화면에 들어오는 순간 자동으로 출발합니다 |
| `ladder.traceMs` | 원이 내려가는 시간(ms) |
| `nav.showBack` / `showNext` | 상단 이동 버튼 표시 여부 — 행사 당일엔 꺼두는 것도 방법입니다 |
| `ending` | 마무리 문구, 신청 링크 QR, `autoRestartSec`(0보다 크면 자동으로 처음 화면 복귀) |

## 알아두면 좋은 점

- **수량 차감 시점**: 상자를 고르는 순간이 아니라 **짜잔 화면에서 상품이 공개될 때** 1개 줄어듭니다. 같은 상자를 뒤로 갔다 다시 봐도 중복 차감되지 않습니다.
- **재도전 가능**: 상단 `이전` 으로 돌아가 **다른 상자**를 고르면 그 상품도 차감됩니다. 한 사람이 여러 번 돌리는 걸 막으려면 `nav.showBack: false` 로 두세요.
- **상자 번호는 고정**입니다. 같은 번호는 항상 같은 상품이라, 시간이 지나면 참여자들끼리 알게 될 수 있습니다. 필요하면 중간에 `prizes` 순서를 바꿔주세요.
- 인터넷 연결 없이도 동작합니다. (외부 라이브러리·폰트 미사용)
