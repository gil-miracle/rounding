# 컨퍼런스 독려 이벤트 (퀴즈 + 사다리타기)

교회 컨퍼런스 홍보용 웹 이벤트입니다. HTML / CSS / JavaScript 만 사용했고,
설치나 서버 없이 **`index.html` 을 브라우저로 열면 바로 실행**됩니다.

> 디자인은 임시(기능 확인용)입니다. 시안이 나오면 `css/style.css` 만 손보면 됩니다.

---

## 화면 흐름

```
인트로  →  퀴즈(4지선다 1문제)  →  상품 선택(6개)  →  사다리타기(5칸)  →  엔딩
```

- 상단에 **이전 / 다음** 버튼과 진행 표시가 있어 자유롭게 이동할 수 있습니다. (키보드 ← → 도 동작)
- 사다리타기는 **5개 선이 동시에 출발**하고, 도착하면 **아래 5칸이 가운데로 모여 하나로 합쳐지면서** 그 자리에 QR 이미지가 나타납니다.
- 내가 고른 줄은 주황색, 나머지 줄은 회색으로 함께 내려갑니다.

## 화면 크기

아이패드 세로(768~834px) 기준으로 맞춰져 있고, 아이폰 등 좁은 화면에서도 자동으로 줄어듭니다.

---

## 폴더 구조

```
index.html            화면 구조
css/style.css         스타일 (디자인 시안 반영은 이 파일에서)
js/config.js          ★ 이벤트 내용 설정 — 보통 이 파일만 고치면 됩니다
js/ladder.js          사다리 생성 · 경로 계산 · 애니메이션
js/app.js             화면 전환과 전체 흐름
assets/qr/*.svg       QR 이미지 (지금은 샘플 자리 이미지)
```

---

## QR 이미지 넣는 법

`assets/qr/` 안의 샘플 파일을 **실제 QR 이미지로 교체**하면 됩니다.

1. 기프티콘/링크 QR 이미지를 `assets/qr/` 에 넣습니다. (png, jpg, svg 모두 가능)
2. `js/config.js` 에서 해당 상품의 `qrImage` 경로를 바꿉니다.

```js
{
  id: 'cafe',
  emoji: '☕',
  name: '카페 기프티콘',
  note: '아메리카노 Tall',
  qrImage: 'assets/qr/cafe.png',   // ← 이 상품의 기본 QR
  results: [
    { label: '아메리카노 당첨!' },                                  // 기본 QR 사용
    { label: '라떼 당첨!', image: 'assets/qr/cafe-latte.png' },     // 이 칸만 다른 QR
    { label: '아메리카노 당첨!' },
    { label: '아메리카노 당첨!' },
    { label: '아쉽지만 꽝!', win: false, caption: '다음 기회에!' }   // QR 없이 꽝 처리
  ]
}
```

- `results` 개수는 `ladder.lanes`(기본 5)와 같아야 합니다.
- 경로가 틀리면 화면에 **"QR 이미지를 찾을 수 없어요" + 찾던 파일 경로**가 표시되니 바로 확인할 수 있습니다.

## 자주 바꾸는 설정 (`js/config.js`)

| 항목 | 설명 |
| --- | --- |
| `intro` | 제목, 부제, 일시/장소, 시작 버튼 문구, 로고 이미지 |
| `quiz` | 문제, 보기 4개, `answerIndex`(정답 번호, 0부터), 정답/오답 문구 |
| `quiz.allowRetry` | `true` 면 맞출 때까지 재도전, `false` 면 한 번에 판정하고 정답 공개 |
| `prizes` | 상품 6개와 각 상품의 결과 5칸 |
| `ladder.lanes` / `rows` | 사다리 칸 수 / 가로 다리 층 수 |
| `ladder.traceMs` | 선이 내려가는 시간(ms) |
| `ladder.shuffleResults` | `true` 면 매 판마다 아래 칸 순서를 섞음 (권장) |
| `nav.showBack` / `showNext` | 상단 이동 버튼 표시 여부 — 행사 당일엔 꺼두는 것도 방법입니다 |
| `ending` | 마무리 문구, 신청 링크 QR, `autoRestartSec`(0보다 크면 자동으로 처음 화면 복귀) |

---

## 알아두면 좋은 점

- **당첨 확률**: 사다리 도착 칸은 거의 균등하게 나옵니다. 여기에 `shuffleResults: true` 로 매 판마다 아래 칸 순서를 섞기 때문에, 꽝을 몇 칸 넣었는지가 그대로 확률이 됩니다. (5칸 중 1칸 꽝 → 20%)
- **재도전 가능**: 상단 `이전` 으로 상품 선택 화면까지 돌아갔다가 다시 들어오면 **새 사다리**가 만들어집니다. 한 사람이 여러 번 돌리는 걸 막으려면 `nav.showBack: false` 로 두세요.
- **QR 소진 관리**: 같은 QR이 여러 사람에게 노출되므로, 한 사람당 하나씩 나가야 하는 기프티콘이라면 운영자가 옆에서 확인해 주시는 편이 안전합니다.
- 인터넷 연결 없이도 동작합니다. (외부 라이브러리·폰트 미사용)
