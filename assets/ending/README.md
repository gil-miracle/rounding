# 엔딩 화면 사진

마지막 화면에 보여줄 사진입니다.

```
assets/ending/photo.jpg
```

- `js/config.js` 의 `ending.image` 가 이 경로를 가리킵니다.
- **정사각형**으로 맞춰져 있습니다. (지금은 800×800, 92KB)
- `ending.image` 를 `''` 로 비우면 사진 대신 신청폼 QR이 나옵니다.

## 원본 보관

나중에 다시 잘라야 할 수 있으니 원본은 이 폴더에 `photo-original.jpg` 로 두세요.
`-original` 이 붙은 파일은 `.gitignore` 에 걸려 있어 배포에는 올라가지 않습니다.
