# 폰트 폴더

첫 화면 **MIRACLE** 제목에 쓰는 `BD Plakatbau` 서체 자리입니다.

## 넣는 법

폰트 파일을 이 폴더에 아래 이름으로 넣어주세요. 하나만 있어도 됩니다.

```
assets/font/bd-plakatbau.woff2   (가장 권장 — 용량이 가장 작음)
assets/font/bd-plakatbau.woff
assets/font/bd-plakatbau.otf
```

- 파일이 없어도 **기기에 BD Plakatbau 가 설치돼 있으면** 그 폰트로 나옵니다.
- 둘 다 없으면 기본 굵은 고딕으로 대체되고, 화면이 깨지지는 않습니다.
- 아이패드처럼 폰트가 설치되지 않은 기기에서도 보이게 하려면 **파일을 넣어야** 합니다.
- `.otf` / `.ttf` 를 가지고 계시면 woff2 로 변환해서 넣는 편이 훨씬 가볍습니다.

> BD Plakatbau 는 유료 서체입니다. 웹에 올려 쓰려면 웹폰트 라이선스가 필요한지
> 구매처(Büro Destruct) 조건을 확인해 주세요.
