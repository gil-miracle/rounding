# QR 이미지 폴더

사다리 도착 화면과 엔딩 화면에 보여줄 **컨퍼런스 신청폼 QR** 을 여기에 넣어주세요.

```
assets/qr/apply.jpg
```

- `js/config.js` 의 `form.image` 가 이 경로를 가리키고 있습니다.
- 파일 이름이나 확장자를 바꾸면 `form.image` 도 함께 바꿔주세요. (png / jpg / svg / webp 모두 가능)
- 정사각형으로 저장하면 가장 깔끔합니다. QR 둘레의 흰 여백은 그대로 두는 편이 인식이 잘 됩니다.
- 파일이 없으면 화면에 **넣어야 할 파일 경로**가 그대로 표시됩니다.

선물별 기프티콘 QR을 따로 쓰고 싶다면 여기에 함께 넣고,
`config.js` 의 각 선물 `qrImage` 에 경로를 적으면 엔딩 화면에 표시됩니다.
