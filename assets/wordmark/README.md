# 워드마크

첫 화면 **MIRACLE** 제목입니다.

```
assets/wordmark/miracle.svg
```

포스터 서체(**BD Plakatbau**, Büro Destruct)로 글자를 찍어 **아웃라인(도형)으로 변환**한
파일입니다. 폰트 파일 자체는 저장소에 넣지 않았습니다.

> 함께 받은 EULA 7항에 *"폰트 파일은 어떤 방식으로도 재배포할 수 없다(내려받을 수 있게
> 두는 것 포함)"* 고 되어 있어, 공개 저장소에 폰트 파일을 올릴 수 없습니다.
> 대신 6항에서 *"제목·로고타입에 글자를 쓰는 것은 허용"* 하고 있어 이 방식으로 만들었습니다.

## 색을 바꾸려면

파일을 열어 `fill="#de5b6b"` 값만 바꾸면 됩니다.

## 다른 글자로 바꾸려면

폰트가 설치된 PC에서 그 글자를 찍고 **윤곽선 만들기(Create Outlines)** 후 SVG 로 저장해
같은 이름으로 덮어쓰면 됩니다. (일러스트레이터·피그마 등)

`js/config.js` 의 `intro.titleImage` 를 `''` 로 비우면 이미지 대신 `intro.title` 글자가 나옵니다.
